# 优化图像模式对比分析和快捷短语

## Goal

优化图像模式下的模式选择、对比分析和快捷短语入口，让生成多张图后的同一聊天记录内对比更自然，减少无用预览和重复命名，同时让快捷短语不占用输入区下方空间。

## What I Already Know

* 图像模式输入框下方目前有“默认模式”和“3D 效果图”两个入口。
* 用户认为这两个入口本质区别是是否追加一段提示词，可以优化，不一定必须保留成两个割裂模式。
* 对比分析应支持在同一个聊天记录内，对该聊天里生成的多张图片进行比较，判断哪个效果更好。
* 当前对比分析下拉里多张图片名称重复，例如都显示 `standard 图1 第1轮`，难以辨认。
* 对比分析里的“预览结果”用处不大，希望移除。
* 快捷短语目前放在输入框下方，视觉上突兀。
* 快捷短语希望移动到右上角“管理快捷短语”下方，默认不加背景，hover 时用阴影表示选中。
* 快捷短语最多显示 10 个，避免过长影响美观。
* 用户也提出可以做成侧边小卡片：需要时弹出点击，不用时收起，不影响主界面美观。

## Assumptions

* 优先复用现有图像生成、聊天记录和快捷短语数据结构，不引入新的复杂状态系统。
* “3D 效果图”更适合作为可开关/可追加提示词预设，而不是独立生成模式。
* 对比分析的范围默认限定为当前聊天记录中的图像结果，不跨聊天会话。

## Open Questions

* None.

## Requirements

* 图像模式里简化“默认模式 / 3D 效果图”的表达：默认模式直通原提示词；3D 作为“提示词增强”开关/预设，不表现为完全割裂的独立模式。
* 对比分析从当前聊天记录里选择多张已生成图片进行比较。
* 对比分析图片选项名称必须能区分不同图片，避免重复名称。
* 移除对比分析里的“预览结果”区域。
* 快捷短语入口从输入框下方移走，避免干扰输入区。
* 快捷短语采用右上角可收起侧边小卡片/抽屉：不用时收起，需要时展开点击。
* 快捷短语展示最多 10 条。
* 快捷短语 hover 状态要有轻量阴影反馈。

## Acceptance Criteria

* [ ] 在同一聊天记录生成多张图片后，对比分析可选择并区分这些图片。
* [ ] 对比分析不再展示“预览结果”。
* [ ] 图像模式的“3D 效果图”不再表现为与默认模式完全割裂的独立模式。
* [ ] 快捷短语不再出现在输入框下方。
* [ ] 快捷短语最多显示 10 条，hover 有阴影反馈。
* [ ] 前端类型检查和相关测试通过。

## Definition of Done

* Tests added/updated where appropriate.
* Lint / typecheck / existing focused tests pass where feasible.
* UI changes follow existing frontend conventions and do not touch unrelated dirty files.

## Out of Scope

* 不重做完整聊天历史系统。
* 不重新设计图片管理页面。
* 不新增跨聊天记录的图片对比。
* 不引入新的图像生成模型或后端生成能力。

## Technical Notes

* 需要检查 `attuno-studio/ui-prototype` 下的聊天输入、图像模式、对比分析和快捷短语相关组件。
* 已定位主要实现集中在 `attuno-studio/ui-prototype/src/App.tsx` 和 `attuno-studio/ui-prototype/src/styles.css`。
* 前端状态 guideline 要求快捷短语是 image workspace composer helper，但这次 UX 将从 composer 下方迁到右侧轻量抽屉，仍只在 image workspace 的 new-generation 场景显示。
* 当前仓库已有大量未提交变更，实施时必须只处理本任务相关文件，避免回退或混入用户/历史改动。

## Technical Approach

* 保留现有 `GenerationMode` 值以降低后端和历史兼容风险，只调整前端文案和控件语义，让 `render3d` 作为“3D 提示词增强”选项呈现。
* 新增当前可见聊天路径中的图片选项派生逻辑，对比分析优先使用当前聊天记录内的 render messages，生成唯一标签用于下拉和图像标题。
* 对比弹窗中移除无用的预览/单图结果区域，保留比较对象选择和并排对比。
* 快捷短语从 composer 底部移到主界面右上角的可收起浮层，最多渲染 10 个短语，hover 阴影反馈，点击仍复用现有插入逻辑。

## Decision (ADR-lite)

**Context**: 现有 UI 把“默认模式”和“3D 效果图”表现为两个模式，但用户感知它们核心区别只是提示词是否被增强；对比分析也更需要同一聊天记录内多图横向比较，而不是全局历史或单图预览。

**Decision**: 保持现有数据/接口兼容，做前端语义和交互调整：`render3d` 显示为 3D 提示词增强；对比分析使用当前聊天路径图片；快捷短语改为可收起浮层。

**Consequences**: 实现范围集中在前端，风险低；未来如果要把“提示词增强”扩展为更多预设，可以在现有控件上继续增加 preset/chip，而不需要改后端生成合同。
