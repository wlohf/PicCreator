# 聊天生图风格对比预览

打开 `style-board.html` 可以查看 4 个视觉方向：

1. Claude + Runway：温暖、安静、适合长时间对话，图片结果区更像创作画廊。
2. Replicate + Cursor：偏模型实验台，适合参数、模型、状态很多的专业工作流。
3. Linear + Vercel：偏高级 SaaS，结构清楚、产品化强。
4. Runway：深色电影感，适合强视觉内容展示，但聊天长时间使用会更有压迫感。

这些预览只用于风格选择，没有接入当前应用。
